Keeping it current

The page is static, so it cannot change itself. A scheduled job in the project repository does the updating and republishes these files.

    Add a data point Run the update now View the code

    Every morning the job pulls new wholesale and crude prices from FRED and the AAA national average, scores yesterday's forecast, and locks in tomorrow's so it can never be edited afterwards. Every Sunday it refits the model on everything collected. “Add a data point” opens a short form on GitHub; entries from project members are added automatically, anyone else's wait for review. “Run the update now” needs a GitHub account with access to the project.

    How it works

    1. Weekly model

    Ten years of EIA retail and wholesale prices train an LSTM that forecasts next week's price change and its uncertainty.

    2. Daily model

    A second LSTM uses the weekly forecast, recent AAA changes, wholesale and crude moves, and a GARCH volatility estimate to forecast tomorrow's change.

    3. Probabilities

    The output is a Student-t distribution. Every threshold question, and every Kalshi strike, is read off its cumulative curve. Three seeds are averaged.
